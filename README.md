# Personal Timeline Builder

A web-based interactive tool for creating and organizing personal timelines.

The project contains multiple standalone HTML versions, representing different iterations of the Personal Timeline Builder as the interface and functionality were developed and refined.

## Features

- Create and organize personal timeline entries
- Interactive timeline-based interface
- Multiple versions for development and experimentation
- Standalone HTML files
- No backend or installation required
- Runs directly in a modern web browser
- Simple and user-friendly interface
